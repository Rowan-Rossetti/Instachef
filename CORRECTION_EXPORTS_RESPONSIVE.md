# Correction des exports et du responsive du Meal Planner

- Le PDF est maintenant généré depuis une feuille A4 paysage dédiée aux dimensions fixes, indépendante du responsive du site.
- Le document Word utilise une section paysage et des hauteurs de lignes fixes afin de conserver le tableau sur une seule page.
- Les textes très longs sont raccourcis proprement dans les fichiers exportés pour éviter toute seconde page.
- Sur le site, le nom de chaque jour reste sur une seule ligne.
- Sous 640 px, le jour reste en haut et les blocs Midi et Soir sont placés verticalement en dessous.
