# Mise à jour du Meal Planner

## Éléments retirés

- Le libellé « Semaine sélectionnée ».
- Le compteur « Jours planifiés ».
- Le compteur « Éléments renseignés ».
- Le compteur « Recettes disponibles ».
- Le bouton global « Effacer ».
- Le bouton d’effacement de chaque journée.

## Fonctionnement corrigé

- Navigation fiable entre les semaines.
- Retour à la semaine actuelle en cliquant sur la période.
- Sauvegarde automatique séparée pour chaque semaine.
- Utilisation d’une date locale pour éviter les décalages de semaine liés au fuseau horaire.
- Validation des données relues depuis le stockage du navigateur.
- Saisie libre dans tous les champs.
- Suggestions provenant des recettes enregistrées.
- Copie d’une journée vers la suivante.
- Export Word.
- Export PDF.
- Impression A4 paysage.

## Vérification

Le registre npm disponible dans l’environnement de modification ne contient pas `@angular-devkit/build-angular@19.2.11`, donc la compilation Angular complète n’a pas pu être lancée ici.
